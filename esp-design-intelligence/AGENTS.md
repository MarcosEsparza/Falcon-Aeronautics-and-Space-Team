# Project Instructions

- Read existing code before modifying it.
- Treat the latest accepted `main` branch as the baseline.
- Keep the code simple and modular.
- Do not create unnecessary wrappers, duplicate functions, or patch layers.
- Preserve existing calculations unless a verified defect or approved requirement justifies changing them.
- Separate engineering calculations, historical analysis, and dashboard presentation.
- Never fabricate real ESP performance data or historical outcomes.
- Clearly identify fictional data and engineering assumptions.
- Add or update tests when changing functionality.
- Report actual test results and unresolved limitations.
- Never claim that passing software tests validates field performance.
